# 🇰🇷 Korean Exchange Market News

Automated KRX (Korea Exchange) market intelligence briefs and post-market reviews, generated via GitHub Actions using NVIDIA NIM + DeepSeek V4 models.

## 📁 Repository Structure

```
.github/workflows/
  morning-brief.yml          # Scheduled at 23:00 UTC (08:00 KST)
  post-market-review.yml     # Scheduled at 06:30 UTC (15:30 KST)
.github/scripts/
  generate_brief.py          # Agent with web search for brief generation
  generate_review.py         # Agent with web search for review generation
prompts/
  morning-brief.md           # Prompt template for morning brief
  post-market-review.md      # Prompt template for post-market review
briefs/
  YYYY-MM-DD-{model}.md      # Generated morning briefs (model-specific)
reviews/
  YYYY-MM-DD-{model}.md      # Generated post-market reviews (model-specific)
scripts/
  review_gate.py             # Date/holiday validation gate
  generate_review.py         # Legacy script (kept for reference)
```

## 🤖 Multi-Model Support

Both workflows support multiple models via `workflow_dispatch` or by modifying the default in the workflow file.

### Supported Models

| Model | Slug | Description |
|-------|------|-------------|
| `deepseek-ai/deepseek-v4-pro` | `dsv4pro` | 1.6T params, 49B active — highest quality |
| `deepseek-ai/deepseek-v4-flash` | `dsv4flash` | 284B params — faster, cheaper |

### File Naming Convention

Each generated file includes the **model slug** in the filename:

```
briefs/2026-04-29-dsv4pro.md        ← Morning Brief by DeepSeek V4 Pro
briefs/2026-04-29-dsv4flash.md     ← Morning Brief by DeepSeek V4 Flash
reviews/2026-04-29-dsv4pro.md      ← Review by DeepSeek V4 Pro
reviews/2026-04-29-dsv4flash.md    ← Review by DeepSeek V4 Flash
```

This allows:
- **A/B testing** different models on the same day
- **Ensemble analysis** — compare briefs/reviews from multiple models
- **Model migration** without losing historical data

Each file also contains metadata in an HTML comment at the top:

```html
<!--
model: deepseek-ai/deepseek-v4-pro
model_slug: dsv4pro
generated_at: 2026-04-29T08:00:00+00:00
prompt_file: prompts/morning-brief.md
-->
```

## 🔧 How It Works

### Morning Brief (23:00 UTC / 08:00 KST)

1. GitHub Actions triggers on schedule
2. Python agent reads `prompts/morning-brief.md`
3. Agent calls NVIDIA NIM API with DeepSeek model
4. **Model can request web searches** via tool-calling loop
5. Agent executes searches using DuckDuckGo
6. Results fed back to model
7. Final brief generated and saved as `briefs/YYYY-MM-DD-{slug}.md`
8. Auto-committed to repo

### Post-Market Review (06:30 UTC / 15:30 KST)

1. GitHub Actions triggers on schedule
2. `scripts/review_gate.py` validates:
   - Is today a KRX trading day? (not weekend/holiday)
   - Has market closed? (≥ 15:30 KST)
   - Does morning brief exist?
3. If gate passes, Python agent reads brief + prompt
4. Agent calls NVIDIA NIM with model
5. **Model requests web searches** for actual market data
6. Agent executes searches, feeds results back
7. Strict data-only review generated
8. Saved as `reviews/YYYY-MM-DD-{slug}.md`
9. Auto-committed to repo

## 🛠️ Web Search Implementation

**NVIDIA NIM does NOT provide native web search.** The models support function calling (tool use), but the actual tool execution must be built by us.

Our agent implementation:
- Detects when the model outputs a ````tool` JSON block`
- Executes the tool (DuckDuckGo search or HTTP fetch)
- Returns results to the model in the next message
- Repeats until the model produces final output

This gives the model **real-time web access** without native tool support from NIM.

## 🚀 Manual Trigger

You can manually trigger either workflow from GitHub Actions tab and select the model:

1. Go to **Actions** tab
2. Select **KRX Morning Brief** or **KRX Post-Market Review**
3. Click **Run workflow**
4. Choose model from dropdown
5. Click **Run workflow**
